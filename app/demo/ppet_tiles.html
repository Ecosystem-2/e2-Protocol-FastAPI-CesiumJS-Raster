🌐 Demonstrated API Endpoints

    
    
Tile Serving:

    
    
      
  • GET /tiles/{asset_id}/{z}/{x}/{y}.png
    
        Serves PNG tiles with colourmap rendering for Cesium visualization
    • 
    

    
    
Polygon Queries:

    
    
      
  • POST /query/polygons/stats
    
        Computes zonal statistics (min/max/mean/std/median) for drawn polygons across multiple assets
    • 
      
  • POST /query/polygons/pixels
    
        Extracts raw pixel values as CSV (lon, lat, asset_id, value) - used by "Export Pixel Data" button
    • 
    

    
    
Asset Discovery:

    
    
      
  • GET /assets
    
        Lists all available climate index assets (used to populate time slice selector)
    • 
    

    
    
💡 All endpoints use FormData for multipart requests. Polygon queries support multiple assets and geometries simultaneously.
