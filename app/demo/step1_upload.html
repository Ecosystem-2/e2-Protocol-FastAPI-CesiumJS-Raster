Upload GeoTIFF Asset

Select a GeoTIFF file containing climate index data (PPET or WBGT). The file will be validated, converted to EPSG:4326, and stored in Google Cloud Storage with metadata persisted to MongoDB.

POST /api/climate-indices/ingest
📋 API Request Example
Required Parameters (Form Data): 
file: File                           # Required, .tif/.tiff binary
index_type: "ppet"                   # Required, climate index type
time_start: "2041-01-01T00:00"       # Required, ISO datetime
time_end: "2070-12-31T23:59"         # Required, ISO datetime
region: "Segama River"               # Optional
scenario: "ssp245"                   # Optional (e.g. SSP2-4.5)
model: "ensemble"                    # Optional, climate model
notes: "Historic baseline data"      # Optional
JavaScript (Fetch API): 
const formData = new FormData();
formData.append('file', fileInput.files[0]);
formData.append('index_type', 'ppet');
formData.append('time_start', '2041-01-01T00:00');
formData.append('time_end', '2070-12-31T23:59');
formData.append('region', 'Segama River');
formData.append('scenario', 'ssp245');
formData.append('model', 'ensemble');
formData.append('notes', 'Historic baseline data');

const response = await fetch('/api/climate-indices/ingest', {
  method: 'POST',
  body: formData
});
const data = await response.json();
Python (requests): 
import requests

with open('climate_data.tif', 'rb') as f:
    files = {'file': f}
    data = {
        'index_type': 'ppet',
        'time_start': '2041-01-01T00:00',
        'time_end': '2070-12-31T23:59',
        'region': 'Segama River',
        'scenario': 'ssp245',
        'model': 'ensemble',
        'notes': 'Historic baseline data'
    }
    
    response = requests.post(
        'http://localhost:8080/api/climate-indices/ingest',
        files=files,
        data=data
    )
    result = response.json()
