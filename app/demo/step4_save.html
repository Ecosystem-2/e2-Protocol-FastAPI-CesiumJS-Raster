Save Selections

Store the polygon and its statistics in MongoDB. Saved selections can be retrieved by name and exported as CZML visualisations in Step 5.

POST /api/climate-indices/selections/save
📋 API Request Example
Required Parameters (Form Data): 
title: "Selection Title"             # Required, 1-200 chars
geometry: "{\"type\":...}"            # Required, GeoJSON string (single or array)
asset_ids: "id1,id2,id3"             # Required, comma-separated
description: "Optional description"  # Optional
tags: "tag1,tag2"                    # Optional, comma-separated
locale_id: "uuid-v4"                 # Optional, for grouping
site_id: "uuid-v4"                   # Optional, auto-generated if not provided
user_id: "uuid"                      # Optional
JavaScript (Fetch API): 
const formData = new FormData();
formData.append('title', 'Segama Delta Heat Stress');
formData.append('description', 'High risk area analysis');
formData.append('tags', 'climate,heat,risk');
formData.append('geometry', JSON.stringify(polygon));
formData.append('asset_ids', 'asset-id-1,asset-id-2');
formData.append('locale_id', 'd35051c9-9444-4367-ae59-e77b9c58f91e');

const response = await fetch('/api/climate-indices/selections/save', {
  method: 'POST',
  body: formData
});
Python (requests): 
import requests
import json

data = {
    'title': 'Segama Delta Heat Stress',
    'description': 'High risk area analysis',
    'tags': 'climate,heat,risk',
    'geometry': json.dumps(polygon),
    'asset_ids': 'asset-id-1,asset-id-2',
    'locale_id': 'd35051c9-9444-4367-ae59-e77b9c58f91e'
}

response = requests.post(
    'http://localhost:8080/api/climate-indices/selections/save',
    data=data
)
