POST /api/climate-indices/sites/{site_id}/export-czml
📋 API Request Example
Parameters (Form Data): 
visualisation_type: "point" | "bar" | "billboard"  # Optional, default: point
colourmap_name: "viridis"                         # Optional, default: viridis
value_field: "mean" | "min" | "max" | "std"       # Optional, default: mean
point_size: 10                                     # Optional, 1-100
bar_height_multiplier: 10000.0                    # Optional
show_labels: true                                  # Optional
JavaScript: 
const siteId = 'dac9b4f8-117f-438e-9601-8a3ef1401a28';
const formData = new FormData();
formData.append('visualisation_type', 'point');
formData.append('colourmap_name', 'viridis');
formData.append('value_field', 'mean');

const response = await fetch(
  `/api/climate-indices/sites/${siteId}/export-czml`,
  { 
    method: 'POST',
    body: formData
  }
);
const czml = await response.json();
Python: 
import requests

site_id = 'dac9b4f8-117f-438e-9601-8a3ef1401a28'
data = {
    'visualisation_type': 'point',
    'colourmap_name': 'viridis',
    'value_field': 'mean'
}

response = requests.post(
    f'http://localhost:8080/api/climate-indices/sites/{site_id}/export-czml',
    data=data
)
czml = response.json()
