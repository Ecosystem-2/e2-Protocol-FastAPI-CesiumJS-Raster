📋 Polygon Query API Examples
POST /api/climate-indices/query/polygons/stats
Query zonal statistics for multiple polygons across one or more climate assets
JavaScript (Fetch API): 
const polygons = [
  {
    type: "Polygon",
    coordinates: [[
      [117.5, 4.5], [117.6, 4.5], [117.6, 4.6], [117.5, 4.6], [117.5, 4.5]
    ]]
  }
];

const formData = new FormData();
formData.append('asset_ids', 'asset-id-1,asset-id-2');
formData.append('polygons_geojson', JSON.stringify(polygons));

const response = await fetch('/api/climate-indices/query/polygons/stats', {
  method: 'POST',
  body: formData
});
const stats = await response.json();
Python (requests): 
import requests
import json

polygons = [
    {
        "type": "Polygon",
        "coordinates": [[
            [117.5, 4.5], [117.6, 4.5],
            [117.6, 4.6], [117.5, 4.6], [117.5, 4.5]
        ]]
    }
]

data = {
    'asset_ids': 'asset-id-1,asset-id-2',
    'polygons_geojson': json.dumps(polygons)
}

response = requests.post(
    'http://localhost:8080/api/climate-indices/query/polygons/stats',
    data=data
)
stats = response.json()

# Response includes: count, min, max, mean, std, median for each polygon
